# Text Editor

A simple text editor built with [Raven](https://github.com/oscar-soirey/Raven). Typing only — no save/open yet.

## Run in VS Code

1. Open the folder, pick a CMake kit, press F5.
2. The first build downloads Raven.

## Package

`bash packaging/package-linux.sh` produces `.deb` in `dist/`.
